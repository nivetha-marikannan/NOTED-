
# Noted App
Noted is a React Native application designed to simplify note-taking and task management. With its clean interface and straightforward functionality, users can efficiently create, edit, delete, and search for notes. This app ensures a smooth and organized experience for managing daily tasks and ideas.

# Key Features

Add Notes: Quickly jot down your tasks or ideas with a title and description.
Edit Notes: Update your existing notes effortlessly.
Delete Notes: Remove unwanted notes with a single click.
Search Functionality: Instantly find notes by searching for their title.
User-Friendly Design: Simple and modern interface for easy navigation.

# Built With

React Native: For cross-platform mobile app development.
Snack Expo: As the development and testing platform.

# How to Use

1. Launch the app and add a new note by entering a title and description.
2. Edit or delete notes directly from the list.
3. Use the search bar to locate specific notes by title.
4. Manage your tasks dynamically with a responsive and intuitive layout.
